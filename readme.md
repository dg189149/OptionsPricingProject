# Option Pricing Calculator

Here is just a little project I am currently working on. You are free to take any parts of code for your own use. The `main.cpp` file is just so I can test the engine as I add more features. Everything used here is in `EuropeanOption.hpp` and in `MathUtils.hpp`

Make sure that in using the engine in your own code you include the block of code below.
```c++
#include "MathUtils.hpp"
#include "EuropeanOption.hpp"
# Include the rest of your libraries here
```

I compiled all code using `c++ -Wall -Wextra -std=c++17`.
